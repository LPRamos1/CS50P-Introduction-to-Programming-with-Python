# Module 00: Functions and Variables

This initial module focuses on the basics of Python syntax, focusing on user input, variable assignment, and mathematical operations.

## 🚀 Key Learning Points
* **Data Types:** Working with strings, integers, and floats.
* **Type Casting:** Converting user input (strings) into numeric types for calculations.
* **String Manipulation:** Cleaning data by removing specific characters like `$` and `%`.
* **Mathematical Logic:** Implementing formulas and handling large integer results.

## 📂 Included Programs

### 1. Einstein (`einstein.py`)
A program that calculates energy based on mass using the famous formula $E = mc^2$. 
* **Input:** Mass as an integer (in kilograms).
* **Output:** Equivalent energy in Joules.
* **Technical Focus:** Demonstrates how Python handles large integers and basic arithmetic.

### 2. Tip Calculator (`tip.py`)
A practical script to calculate the appropriate tip for a meal.
* **Input:** Price of the meal (e.g., `$50.00`) and the tip percentage (e.g., `15%`).
* **Output:** The calculated tip amount formatted as a float.
* **Technical Focus:** Showcases string cleaning (removing symbols) and converting formatted text into calculable floats.
